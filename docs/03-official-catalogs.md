# Vendor and platform resources

Major vendors and platforms that support agent skills often publish **official documentation** and **skill catalogs**—collections of ready-made or example skills for their tool.

---

## What you’ll find there

- **Format and behavior** – How that platform loads skills, where to put them, and any quirks.
- **Example skills** – Commit messages, code review, testing, API usage, and more. Useful as references for structure and description wording.
- **Best practices** – How to write descriptions, when to use personal vs project skills, and how to keep skills maintainable.

You don’t have to use their examples as-is. Treat them as patterns: copy the structure, adapt the description and steps for your own workflow.

---

## Where to look

- **Your tool’s docs** – Search for “skills” or “agent skills” in the official documentation for Cursor, VS Code, Copilot, Claude Code, Codex, or whatever you use. That’s where you’ll get the correct paths and behavior.
- **Your vendor’s site** – Many vendors host a skill catalog or “skills” section (e.g. under developer or product docs). Look for a “Skills” or “Extensions” area that lists or links to example skills.

If you use more than one tool, you’ll see the same SKILL.md format in different places; only the install path and loading details change.
